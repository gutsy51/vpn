# Сценарии разработки

Для новой операции сначала определите узел, входные данные и результат. Проведите
операцию через CLI с тестовым транспортом, затем подключите ботов к тому же коду.
Для команд управления проверьте отказ и неопределённый исход после обрыва связи.
