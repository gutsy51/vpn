# Сценарии разработки

## Добавить проверку для CLI и ботов

Для нового сервера или панели добавьте запись в локальный TOML по образцу
ops/monitor.example.toml. Укажите имя, тип tcp или https и адрес назначения.
Для HTTPS задайте ожидаемый статус. Признак public открывает проверку обычным
пользователям чата. Закрытую проверку может вызвать администратор.

Для нового типа проверки обновите Check, validate_check и probe_check в
monitoring/probes.py. Проверьте результат на локальном сервере. Команды /checks
и /check используют тот же конфиг, что и monitor run. Для новой команды бота
добавьте обработку и справку в messaging/commands.py. Проверьте обе роли
в tests/test_service.py. Детали Telegram и MAX держите в модулях платформ.

## Изменить операцию провайдера

Проверьте существующие команды в console/arguments.py и providers.py.
Для AdminVPS проверьте формирование аргументов ssh с подменой subprocess.run.
Для Fornex подмените вызов API. В тесте проверьте аргументы запроса и результат
для пользователя. Запустите uv run pytest из корня репозитория.
